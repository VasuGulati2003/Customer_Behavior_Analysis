# Customer_Behavior_Analysis
Analyzed 3,900 customer records using Python, MySQL, and SQL. Built an interactive Power BI dashboard with 3 KPI cards and 6 visualizations to explore customer behavior, sales, revenue, subscriptions, and purchasing patterns.
📊 End-to-End Data Analysis Project

Customer Shopping Behavior Analysis

📌 Overview

This project analyzes customer shopping behavior to identify purchasing patterns, sales trends, revenue performance, and subscription insights. It uses Python for data cleaning and exploratory data analysis (EDA), MySQL for SQL analysis, and Power BI to build an interactive dashboard.

📊 Dataset

Records: 3,900 customer records

Domain: Retail and customer shopping behavior

Key information: Customer demographics, product categories, purchase amounts, discounts, subscriptions, and review ratings.

🛠️ Tools & Technologies

Python: Data loading, cleaning, and EDA

Pandas: Data manipulation and analysis

Jupyter Notebook: Python analysis

MySQL: Database storage and SQL queries

Power BI: Interactive dashboard and visualizations

Gamma: Project presentation

Microsoft Word/PDF: Project report

🔄 Project Workflow

Data Loading: Imported the dataset into Python using Pandas.

Exploratory Data Analysis: Examined data structure, distributions, and purchasing patterns.

Data Cleaning: Handled missing values, standardized column names, and prepared data for analysis.

SQL Analysis: Loaded the cleaned dataset into MySQL and executed queries to analyze customer behavior, revenue, discounts, and subscriptions.

Dashboard Development: Created an interactive Power BI dashboard with KPI cards, charts, and filters.

Reporting: Documented the methodology, analysis, and findings in a project report.

Presentation: Created a project presentation using Gamma.

📈 Dashboard

The Power BI dashboard includes:
Total number of customers
Average purchase amount
Average review rating
Customer subscription analysis
Revenue and sales by product category
Revenue and sales by age group

Interactive filters for customer demographics, subscription status, category, and shipping type

🔍 Key Results

Analyzed 3,900 customer records.
Reported an average purchase amount of $59.76.
Reported an average review rating of 3.75.
Used SQL analysis and interactive visualizations to explore customer purchasing behavior and revenue patterns.
